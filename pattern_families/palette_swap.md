# Color Palette Swap

## Failure Mode
An intentional or accidental substitution of the color palette — traditional colors replaced with acid, fluorescent, or entirely wrong-era substitutes. The pattern geometry remains intact; the color relationships are systematically replaced.

## Visual Signature
- Recognizable traditional pattern (tartan, ikat, batik, toile) rendered in completely wrong palette
- Fluorescent colors where earth tones are expected, or vice versa
- Hue relationships may be preserved (light/dark, warm/cool) but with wrong actual colors
- Sometimes: a single color substituted, all others correct — the cuckoo-in-the-nest effect
- Color that would never be achieved with traditional dyestuffs: process magenta in handwoven tweed

## Failure Origin
Intentional artistic choice OR genuine error: dye batch labeled incorrectly, wrong dye recipe applied to correct pattern, digital color profile mismatch during screen preparation.

## Substitution Types
| Type | Description |
|------|-------------|
| Acid substitution | Traditional natural dyes → acid dyes (brighter, more saturated) |
| Fluorescent | Any palette → neon equivalent |
| Inverted | Each color replaced by its complement |
| Monochrome | All colors → grayscale |
| Single swap | One color replaced, others intact |
| Cultural collision | One tradition's palette applied to another's pattern |

## Prompt Template
> "A traditional Fair Isle sweater pattern in fluorescent acid colors — the geometric sheep and snowflake motifs structurally perfect, but rendered in process magenta, acid yellow, electric blue, and UV-reactive orange instead of the expected natural wool palette, the pattern correct and the color entirely wrong"

## Anti-Drift Notes
- Palette swap is **systematic** — not random per thread
- The underlying pattern must be **recognizable as belonging to a specific tradition**
- Do not confuse with channel swap (technical error) — palette swap can be intentional aesthetic choice
